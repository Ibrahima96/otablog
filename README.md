## 🔮 À Propos

**OtaBlog** n'est pas juste un blog, c'est un hub immersif où la culture Otaku rencontre le design futuriste (Cyberpunk/Neon). C'est un espace pour :
- Débattre dans **Le Salon**.
- Partager des créations et des trouvailles dans **La Communauté**.
- Interagir avec **OtaBot**, notre arbitre IA.
- Élire le **Champion de la Semaine**.

## ✨ Fonctionnalités

### 🏠 Hub Principal
- **Design Immersif** : Interface sombre, néons, animations fluides et esthétique "Glassmorphism".
- **Galerie Flottante** : Présentation visuelle des tendances actuelles.
- **Champion de la Semaine** : Mise en avant des personnages ou membres élus par la communauté.

### 💬 Le Salon (The Living Room)
- **Chat en Temps Réel** : Discussions instantanées avec les autres membres.
- **Messages Vocaux** : Envoyez des notes vocales (avec une interface mobile optimisée).
- **Partage de Médias** : Images et photos directement dans le chat.
- **Salons Thématiques** : Différents canaux pour différents sujets.

### 🌐 La Communauté
- **Fil d'Actualité** : Découvrez les derniers posts, vidéos et images.
- **Marketplace** : Achetez ou vendez des articles de collection (figurines, mangas, etc.).
- **Système de Likes & Commentaires** : Interagissez avec le contenu.

### 🤖 OtaBot & IA
- **Arbitre IA** : Un assistant intelligent pour modérer les débats ou répondre aux questions sur l'univers Otaku.
- **Terminal Chat** : Interface de chat dédiée avec l'IA.

## 🛠 Stack Technique

Ce projet est propulsé par des technologies modernes pour assurer performance et fluidité :

- **Frontend** : [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **Styling** : [Tailwind CSS](https://tailwindcss.com/) (avec animations personnalisées)
- **Backend / Base de Données** : [Supabase](https://supabase.com/) (PostgreSQL, Auth, Realtime, Storage)
- **Icônes** : [Lucide React](https://lucide.dev/)
- **IA** : Intégration Gemini / Llama (via services dédiés)

## 🚀 Installation

Pour lancer le projet localement sur votre machine :

1. **Prérequis** : Assurez-vous d'avoir [Node.js](https://nodejs.org/) installé.

2. **Installation des dépendances** :
   ```bash
   npm install
   ```

3. **Configuration** :
   - Créez un fichier `.env` à la racine si nécessaire (se référer à `.env.example` ou aux instructions de l'équipe).
   - Assurez-vous que les variables d'environnement pour Supabase et l'IA sont configurées.

4. **Lancement** :
   ```bash
   npm run dev
   ```
   L'application sera accessible sur `http://localhost:5173`.
